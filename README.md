# 🎓 Student Score Prediction - Machine Learning Project

## 🚀 Internship Project (Decodelabs)

This project predicts student exam scores based on study hours using machine learning.

---

# 📌 Project Overview

A complete end-to-end ML pipeline including:

- Data Understanding
- Data Cleaning
- Exploratory Data Analysis
- Visualization
- Regression Model

---

# 🧩 Task Breakdown

---

## 📊 Task 1: Data Understanding
- Loaded student dataset
- Checked structure using `info()` and `describe()`
- Identified relationship between study hours and scores

---

## 🧹 Task 2: Data Cleaning
- Checked for missing values (none found)
- Removed duplicates if any
- Confirmed dataset is clean and ready

---

## 📈 Task 3: Exploratory Data Analysis (EDA)
- Analyzed correlation between variables
- Found strong positive relationship
- Confirmed linear trend in data

---


## 🤖 Task 5: Machine Learning Model
- Used Linear Regression
- Trained model on study hours
- Predicted student scores
- Evaluated using R² score
- Visualized predictions vs actual values

---

# 📊 Results
- Strong linear relationship observed
- High prediction accuracy
- Simple and effective regression model
